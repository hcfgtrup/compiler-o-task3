# Компилятор языка «О» — Вариант 8

**Задание:** Логические операции (&, OR, ~) без логических переменных.

## Требования

- CMake 3.14+
- Компилятор C++17 (GCC 9+, MSVC 2019+, Clang 10+)
- (опционально) Docker для запуска в контейнере

## Что реализовано

- **Лексер:** распознаёт `&`, `OR`, `~` как отдельные токены.
- **Парсер:** функция `logicalExpressionPrc` разбирает логические выражения
  с самым низким приоритетом. Унарный `~` обрабатывается в `multiplierPrc`.
- **Генератор:** реализует логические операции через условные переходы ОВМ
  (сравнения не оставляют 0/1 на стеке, а генерируют `IFxx`-переходы).
- **ОВМ:** не изменялась, все операции сделаны существующими командами.

## Как собрать

```bash
mkdir build && cd build
cmake ..
cmake --build .
```

## Как запустить основной тест

```bash
Compiler.exe test_logic.o
```

**Ожидаемый вывод:**
```
1
2
3
```

## Дополнительный тест (отрицательные случаи)

```bash
Compiler.exe test_neg.o
```

**Ожидаемый вывод:** три пустые строки (без чисел).

## Запуск через Docker

Собрать образ:
```bash
docker build -t compiler-o .
```

Запустить основной тест:
```bash
docker run --rm compiler-o
```
Ожидаемый вывод: `1`, `2`, `3`.

Запустить тест с отрицательными случаями:
```bash
docker run --rm compiler-o ./build/Compiler test_neg.o
```
Ожидаемый вывод: три пустые строки.

## Ограничения

Виртуальная машина (ОВМ) не изменялась — все логические операции
реализованы существующими командами ОВМ.
